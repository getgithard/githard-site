# Code of conduct

The GitHard website follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be kind, assume good faith, and keep criticism about the work.

To report behaviour that breaks it, contact the maintainer privately through [jamesconway.dev](https://jamesconway.dev/). Reports are kept confidential.
